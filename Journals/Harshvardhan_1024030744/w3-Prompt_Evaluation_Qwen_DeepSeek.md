# Week 3: Coding Prompt Evaluation Using Qwen2.5-Coder 14B and DeepSeek Coder V2 16B

## Work Completed

During this week, I focused on running the coding prompts using two local Large Language Models (LLMs): **Qwen2.5-Coder 14B** and **DeepSeek Coder V2 16B**. The objective was to test both models with the same prompts and observe the code and explanations generated by each model.

### Qwen2.5-Coder 14B Prompt Execution

I used **Qwen2.5-Coder 14B** to run the coding prompts prepared for the evaluation.

For each prompt, I submitted the programming task to the model and reviewed the response generated. The purpose was to check how the model interpreted the task and how it presented the requested code or explanation.

The prompt execution workflow was:

**Coding Prompt → Qwen2.5-Coder 14B → Generated Response**

### DeepSeek Coder V2 16B Prompt Execution

I also ran the coding prompts using **DeepSeek Coder V2 16B**.

The same prompts were used with this model so that the outputs could be reviewed alongside the responses from Qwen2.5-Coder 14B. This provided a consistent basis for examining the responses produced by both models.

The prompt execution workflow was:

**Coding Prompt → DeepSeek Coder V2 16B → Generated Response**

### Review of Model Responses

After running the prompts, I reviewed the generated responses from both models. The review focused on the following aspects:

* Whether the response addressed the requirements in the prompt.
* Whether the generated code was presented clearly.
* Whether the explanation, when provided, was understandable.
* Whether the outputs from the two models differed in approach or presentation.
* Which responses would need further checking or execution before being considered correct.

The generated code should be compiled or executed and checked against the task requirements before drawing conclusions about correctness.

### Comparative Prompt Workflow

Using the same prompts with both models established the following workflow:

**Same Coding Prompt → Qwen2.5-Coder 14B → Response Review**

**Same Coding Prompt → DeepSeek Coder V2 16B → Response Review**

This approach keeps the prompts consistent and makes it easier to review the models' outputs side by side.

### Key Observation

Running the same prompts through **Qwen2.5-Coder 14B** and **DeepSeek Coder V2 16B** provides a basis for comparing their generated code and explanations. Any conclusion about which model performs better should be based on checking the actual outputs for correctness, completeness, and compliance with each prompt.
