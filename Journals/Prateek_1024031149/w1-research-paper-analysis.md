# Week 1 : Research Paper Analysis and Dataset Creation

## Research Paper Studied

**CoDyn: Dynamic LLM Routing for Coding Tasks**

[Research Paper](https://openreview.net/pdf?id=0ox03jE6jb)

## Work Completed

Studied and analyzed the CoDyn paper to understand how dynamic LLM routing can be used to select different models for different coding tasks.

The paper evaluates multiple Llama models across different coding datasets and creates routing data by comparing the performance of different models on the same prompts.

## Key Observation

The paper's results show that the best model can vary significantly between individual prompts. The winner-change rate was **89.8% for APPS, 86.8% for Code Translation, 75.0% for Code Refinement, and 78.5% for RunBugRun**. This indicates that using a single strongest model for every prompt may not be the most efficient approach.

The paper's LLM Classifier was also able to generally match or surpass the strongest individual model while achieving approximately **43% of the strongest model's cost** on average.

## Project Direction

Based on the paper's findings, we decided to develop a smaller-scale routing system suitable for our available resources rather than reproducing the experiment at the same scale.

We also decided to investigate **token consumption as the primary efficiency metric** instead of depending entirely on paid API costs. The paper itself notes that fixed model-level costs do not fully capture differences in the number of tokens generated by different models.
